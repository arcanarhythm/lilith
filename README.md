# LILITH — Индивидуальный проект-погружение

Этот репозиторий содержит готовый сайт-лендинг для проекта **LILITH**.

## Инструкция по деплою на GitHub Pages:
1. Загрузите файлы из этого архива в ваш GitHub репозиторий.
2. Перейдите в **Settings -> Pages**.
3. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
4. Нажмите **Save**. Сайт будет доступен через 1-2 минуты!
