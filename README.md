# Инструкция по запуску сайта LILITH на GitHub Pages

1. **Распакуйте этот архив** в папку на вашем компьютере.
2. **Изображения:** 
   Убедитесь, что все файлы изображений из архива находятся в одной папке с `index.html`.
3. **Публикация на GitHub Pages:**
   - Создайте репозиторий на GitHub.
   - Загрузите все файлы из этого архива (`index.html` и все картинки `.png`/`.jpg`).
   - Перейдите в **Settings** -> **Pages**.
   - В разделе **Branch** выберите `main` (или `master`) и нажмите **Save**.
   - Через 1-2 минуты ваш сайт будет доступен по ссылке GitHub Pages!
